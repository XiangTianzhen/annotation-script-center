## 阅读顺序

1. 先阅读当前任务读取，确认页面上下文来源。
2. 再阅读标注存储与暂存，理解平台原生保存链路。
3. 最后阅读提交契约，确认最终字段职责与原生按钮边界。

## 通用约定

- 路径只记录 pathname，示例参数统一使用占位符。
- 响应只记录接入所需的字段职责，不保存完整业务数据。
- 运行时观察请求获取最小上下文；页面写入使用 DOM 和平台事件，暂存快捷键只点击页面原生暂存按钮。
- 最终提交仍由用户触发平台原生按钮，不由扩展直接调用提交接口。

## 当前边界 / 待补项

- 音频真实 pathname 及授权方式尚未确认；捕获的媒体字节仅转为内存 `audioDataUrl`，不保存资源 URL。
- 暂存接口的完整请求体和服务端幂等行为尚未形成可安全固化的样例。
- 后续补充必须使用脱敏 HAR 或安全测试条目，不得保存临时凭证、签名地址或真实业务内容。
