# 当前任务读取

## 请求标识 / 目的

`GET /web-task-alone-api/task/piece/execute`

用于分段标注页读取当前执行条目的上下文、已有标注引用和页面初始化数据。

## 页面入口 / 触发动作

- 页面：`/workbench/piece/mark.html?taskId={taskId}&executeClass=TAG_PIECE`
- 触发：进入页面或平台原生流程切换到下一条时由页面发起。

## 请求摘要

- 方法：`GET`
- 查询上下文包含任务标识和执行类型；具体取值不得写入资料。
- 后续观察器只提取当前功能所需的最小字段，不保存完整请求 URL 或请求头。

## 请求体摘要

GET 请求无请求体。

## 响应摘要

成功响应提供当前条目数据、既有临时标注信息及页面初始化所需元数据。资料不固化完整响应，只保留后续识别与分段关联所需的脱敏字段映射。

## 关键字段

| 字段 | 职责 |
|---|---|
| `taskId` | 当前任务上下文标识 |
| `dataId` | 当前数据条目标识，提交与暂存时用于对题 |
| `executeClass` | 当前执行类型，分段标注为 `TAG_PIECE` |
| `isValid` | 当前条目的整体有效性状态 |
| `tempInfo` | 已暂存结果的引用或状态；只按实际响应消费 |
| `detail` | 当前条目展示与标注初始化数据；仅做最小化提取 |
| `data.detail.fileFolder` | 当前条目的完整 HTTPS 音频地址；运行时只接受已确认的数加加存储域名 |

## 前端接入建议

- 使用页面世界观察器被动捕获响应，并按当前路由与 `dataId` 对题。
- 观察器在 `document_start` 安装；若脚本设置尚未加载，只在 MAIN world 内存保留最近一次 `taskId + dataId + fileFolder` 最小快照，确认启用后立即消费，禁用或切题时清除。
- 从响应中一次性提取 `data.detail.fileFolder`，在页面世界读取音频并转为临时 `audioDataUrl`；原始地址不得跨世界发布、持久化或记录。
- 观察器只发布识别、分段和写回确认所需的最小快照，不持久化完整响应。
- 页面切题或 iframe 重载后废弃旧快照，避免跨题写入。

## 风险 / 未确认项

- GET 请求是否同时产生领取或执行状态变化尚未确认，扩展不得为补获音频而主动重放。
- 除已确认的 `data.detail.fileFolder` 外，`detail` 与 `tempInfo` 的其他精确嵌套结构仍需以脱敏样例补充。
- 展示名称、`dataName`、`dataPath` 或其他占位路径不能作为音频地址依据。
