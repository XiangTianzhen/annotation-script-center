## 后续首版边界

后续进入真实功能阶段时，首版目标固定为：

- 当前段音频识别。
- 用户选中段的批量识别。
- 整音频分段建议。
- 所有识别或分段结果先预览，用户确认后再通过 DOM 和平台事件写入。
- 段落有效性只由用户显式设置。

运行时采用网络观察获取当前上下文，使用 DOM 和平台事件修改分段与文本，由平台原生逻辑自动暂存；最终提交与进入下一条使用页面原生按钮。

不得保存或传输 Cookie、Authorization、临时凭证、签名参数、完整音频地址、用户信息或真实任务数据。音频真实请求确认前，不得根据 `dataName` 或占位 `dataPath` 推断媒体地址。
