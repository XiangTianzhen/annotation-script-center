# 数加加页面结构索引

## 目录定位

本目录保存数加加分段标注页当前有效的稳定 DOM 结构、选择器和运行时挂载边界。

## 适用范围 / 当前覆盖

当前覆盖 `/workbench/piece/mark.html` 外层页面及 `#bdIframe` 内嵌编辑器，包括原生提交按钮、波形、分段表格、转写输入和段落有效性区域。

## 文件列表

- [分段标注页结构](01-piece-mark.md)

## 阅读顺序

直接阅读分段标注页结构；涉及请求字段时再对照 [Network 契约](../network/README.md)。

## 通用约定

- 优先使用稳定 class、iframe ID、控件语义和表头关系，不依赖动态 ID。
- 每次操作前重新解析可见 DOM，避免复用重渲染前的节点引用。
- 运行时只在 iframe 内按这些稳定语义重新解析节点，不缓存跨重渲染引用。

## 当前边界 / 待补项

- 内层编辑器部分控件仅确认了可见语义，尚未形成跨任务样本的唯一稳定选择器。
- 真实页面已确认 `.audio-peaks .waveform`、`.center-tools` 画段工具、`.center .pause` 播放控件与外层原生暂存按钮；跨更多任务样本的稳定性仍需继续观察。
- 当前仅允许零段落整音频划为一个段落，其他分段编辑不在首版范围。
