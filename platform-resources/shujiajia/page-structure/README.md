# 数加加页面结构索引

## 目录定位

本目录保存数加加分段标注页当前有效的稳定 DOM 结构、选择器和未来挂载边界。

## 适用范围 / 当前覆盖

当前覆盖 `/workbench/piece/mark.html` 外层页面及 `#bdIframe` 内嵌编辑器，包括原生提交按钮、波形、分段表格、转写输入和段落有效性区域。

## 阅读顺序

直接阅读分段标注页结构；涉及请求字段时再对照 [Network 契约](../network/README.md)。

## 通用约定

- 优先使用稳定 class、iframe ID、控件语义和表头关系，不依赖动态 ID。
- 每次操作前重新解析可见 DOM，避免复用重渲染前的节点引用。
- 当前资料只用于未来设计，不代表扩展运行时代码已接入。

## 当前边界 / 待补项

- 内层编辑器部分控件仅确认了可见语义，尚未形成跨任务样本的唯一稳定选择器。
- 波形分段事件、选中段状态和平台自动暂存完成信号需在安全测试条目中继续确认。
- 当前不创建扩展挂载点、不注入面板、不执行任何页面写操作。
