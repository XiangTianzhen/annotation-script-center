# 返修详情单题导入与人工结果回填

## 页面标识 / 路由 / 前置条件

- 路由：`/management/task-v2/{taskId}/modify-v2/4/{itemId}`，query 可包含方向、筛选和索引，但不参与题目身份判断。
- 前置条件：台州话脚本已启用；单题导入还要求同任务、同 ItemID、未过期的 `SearchModifyItem` 最小快照。

## 页面总览

- 页面保留只读辅助模式，不开放原有分段、暂存或自动化写入能力。
- 辅助面板显示“添加数据”、录音结果刷新和“填入审核结果”；不显示自动押后的开始/停止区域。

## DOM 树 / 区域结构

- 当前题身份：路由最后一段 `{itemId}`。
- 扩展辅助面板：台州话既有面板根节点。
- 目标转写框：页面中唯一可见、启用、非只读且不位于扩展、弹层或对话框内的 `textarea`。

## 稳定选择器表

| 目标 | 选择器 / 条件 | 用途 |
| --- | --- | --- |
| 当前题 | 路由 `{itemId}` | 导入、刷新与结果回填的唯一题目键 |
| 添加入口 | `[data-recording-import-add='true']` | 单题人工导入 |
| 刷新入口 | `[data-recording-result-refresh='true']` | 查询当前 ItemID 的录音结果 |
| 回填入口 | `[data-recording-result-fill='true']` | 人工触发安全 DOM 追加 |
| 目标文本框 | 唯一满足安全条件的 `textarea` | 换行追加完成文本 |

## 动态区域 / 重渲染风险

- 切题或慢响应可能导致旧结果晚到；点击前必须重新读取路由 ItemID，并拒绝不匹配结果。
- textarea、扩展面板和弹层可能同时存在；候选不是唯一时必须拒绝回填。

## 可挂载点建议

- 复用台州话现有波形区后的辅助面板，不在原生审核按钮附近增加快捷入口。
- 回填按钮仅在 `COMPLETED` 且结果文本非空时进入候选可用状态，最终安全条件仍在点击时重新校验。

## 页面区域与接口映射

| 页面区域 | 数据 / 接口 |
| --- | --- |
| 单题导入上下文 | 同题 `SearchModifyItem` 脱敏快照 |
| 录音状态与文本 | 既有只读结果接口和本地安全映射 |
| 审核结果回填 | 当前页面 textarea 的 DOM value 与 `beforeinput/input/change` 事件 |

## 写操作边界 / 未确认项

- 仅允许用户点击后把完全匹配当前 ItemID 的 `COMPLETED` 非空文本换行追加；相同文本已在末尾时保持不变。
- 禁用、只读、隐藏、扩展内、弹层内或多个 textarea 均拒绝。回填不调用平台接口。
- 不自动暂存、审核、提交、切题或押后；回填后必须由用户人工检查并使用平台原生操作。
