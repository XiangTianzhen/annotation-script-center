# 返修列表当前页录音数据导入

## 页面标识 / 路由 / 前置条件

- 路由：`/management/task-v2/{taskId}/node/14/revise?page={page}`。
- 前置条件：台州话脚本已启用，录音任务编号已配置，并捕获到与当前任务、页码一致且未过期的 `SearchModifyItem` 最小快照。

## 页面总览

- 页面原生区域展示返修包当前页列表。
- 扩展增加“台州话返修数据导入”卡片，只负责把当前已加载页最多 10 条逐项发送到录音平台。

## DOM 树 / 区域结构

- 页面主区：优先使用原生 `main`，缺失时回退 `body`。
- 扩展卡片：`[data-asc-taizhou-revise-import-card='true']`。
- 卡片包含标题、开始按钮、停止按钮和统计状态文本。

## 稳定选择器表

| 目标 | 选择器 / 标识 | 用途 |
| --- | --- | --- |
| 导入卡片 | `[data-asc-taizhou-revise-import-card='true']` | 防止重复挂载与离页清理 |
| 当前页面范围 | `location.pathname + location.search` | 分页、任务或路由变化时停止 |
| 数据范围 | `SearchModifyItem` 最小快照 | 当前页最多 10 条的串行队列 |

## 动态区域 / 重渲染风险

- AIDP 使用前端路由，分页可能只更新 URL 与列表数据而不刷新文档。
- 扩展每次同步重新核对 pathname、search 和安全快照；scope 变化即停止并销毁旧 runtime。

## 可挂载点建议

- 卡片放在 `main` 首部，保持与现有辅助面板一致的白色卡片、圆角、边框和轻阴影视觉。
- 任务编号缺失、快照等待/过期/错页/空内容时禁用开始并显示具体原因。

## 页面区域与接口映射

| 页面区域 | 数据 / 接口 |
| --- | --- |
| 当前页队列 | `SearchModifyItem` 脱敏快照 |
| 单条导入 | 既有脚本中心 `recording-items` 接口 |
| 幂等与复用 | `recordingTaskCode + AIDP ItemID` |
| 统计 | 扩展当前内存中的控制器状态 |

## 写操作边界 / 未确认项

- 严格串行，运行期间 single-flight；停止只阻止下一条，已发出的单条请求允许结算。
- 不翻页、不打开详情、不点击暂存、审核、提交、押后或下一题，不调用任何 AIDP 写接口。
- 页面真实列表 DOM 仍可能调整；卡片只依赖通用主区挂载，不解析人员、审核或其他返修字段。
