# 台州话 AIDP 运行时

## 定位

台州话脚本用于诊断百炼模型与标注平台模型的差异：每段音频只请求一次 Qwen Omni，后端再将字符串原始输出逐字符映射为 `listenText` 供平台文本框使用。

## 原始听音直填契约

- 后端成功结果的唯一业务文本字段是 `listenText`；它是扩展/API 兼容字段，不是模型要求返回的 JSON 字段。
- `listenText` 按原样传递；不做 trim、空白折叠、普通话转换、数字改写、标点规整或重复压缩。
- 后端只在原始模型输出为字符串时逐字符映射 `listenText`；空字符串或非字符串不写入 textarea 或暂存数据。所有非空字符串均会原样写入，包括模型意外输出的 JSON、Markdown 或解释文字。
- 单段与行内识别通过真实 textarea 的输入事件直接写入 `listenText`。
- 批量只处理当前题当前页选中的段，收集非空 `listenText` 后一次通过 `SubmitTempItemAnswer` 写入 `regions[*].txt`。
- 批量停止后不再发新请求；已在途结果不会产生二次写回操作。
- 全程不触发保存、提交或切题，且不修改 `regions[*].ms`。

## 界面与设置

- 行内按钮始终为“识别音频”；不保留待填入、强制填入或风险提示状态。
- AI 信息区显示“原始听音”、调用消耗以及 `raw/debug`。
- Options“基础设置”的“录音平台任务编号”默认空且保存时去除首尾空白；空值不显示导入按钮，也不查询结果。
- 配置任务编号后，详情页顶部只在 Search Item 与当前 Receive ItemID 一致、快照有效且至少包含一种参考内容时启用“添加数据”，按钮固定在“清空画段”左侧。单次 Search Item 响应包含多条数据时，会先提取全部条目的最小安全字段，再按当前 Receive ItemID 精确选择，不固定取第一条，也不按页面位置猜测。等待、过期、错题或空内容时按钮保持禁用，并通过按钮悬停说明具体原因；这些被动状态不覆盖顶部公共状态或导入、刷新、识别等主动操作结果。切换题目时顶部恢复“台州话脚本已就绪，可使用当前页面中的辅助功能。”。导入固定使用当前完整题目，不按画段拆分；用户点击“添加数据”始终由脚本中心核验服务器映射，已有条目以 HTTP 200 恢复并刷新结果，只有录音平台明确返回原条目不存在时才重新创建。
- Search Item 的公网 HTTPS 音视频地址不由扩展下载；“添加数据”只把参考文字和原始 URL 发送到脚本中心创建端点，浏览器不会产生媒体 GET 或参考媒体上传请求，也不会发送 AIDP Cookie、Authorization 或 Session。
- “当前媒体信息”默认折叠，从当前 Receive 条目展示音频和视频地址，不展示模板；存在对应地址时可复制保留完整查询参数的 URL，缺少视频时只显示“无视频”。录音任务导入仍使用 Search Item 一致性校验，并由脚本中心语法校验后直接转发 URL。
- 辅助面板“当前录音平台结果”默认折叠；界面不显示内部关联用的 sourceItemId，始终显示“录音条目”，未导入时显示“还未导入该条目”，导入后显示 itemCode、友好状态、完成文本和音频。HTTP 201 首次创建或 HTTP 200 幂等恢复映射后，先展示创建响应中的真实 itemCode 与 status，再立即查询一次最新结果；自动查询失败只提示可手动刷新，不删除映射、不回滚条目或把创建判定为失败。同步映射变化不参与台州话运行时配置签名，保存映射不会销毁当前 Search Item 快照和录音上下文；任务编号、后端地址、AI 与分段等真实配置变化仍会重建运行时。状态映射覆盖待领取、待录音、待审核领取、审核中、待返修、已完成和已废弃，未来未知状态直接显示原始状态码。任何映射读取前先登记题目与进入代次，每次进入匹配题目只读取本地映射并自动查询、渲染一次；同题目的周期性 DOM 同步直接跳过，不再读取映射、查询缓存、渲染结果或重建音频播放器。只有用户点击“刷新录音结果”且本地映射缺失时，扩展才使用当前完整题目调用只读恢复接口；服务器映射及参考指纹匹配后重建本地安全映射并返回最新结果，服务器也无映射时保持正常空状态，绝不创建录音条目。A→B→A 再次进入 A 时创建新代次并重新查询，旧题的慢映射、结果和错误不渲染。AIDP 重建辅助面板时直接从 UI 内存恢复最近结果，不调用服务器。结果音频只接受脚本中心预期相对 API 路径及双段 base64url token，不展示结果视频、不写回 AIDP。
- 人工导入固定使用启动时的任务编号与 sourceItemId；导入中切题仍只保存原题映射，不把原题成功或失败状态渲染到新题。
- “全自动导入并押后”位于辅助面板，默认待命，只有用户点击“开始”才处理当前 AIDP 任务；不保存运行状态，刷新页面、重载扩展或运行时重建都会停止。每轮复用“添加数据”后刷新结果的流程；已有映射也必须刷新到 `AVAILABLE`（待领取）或 `SUBMITTED`（待审核领取）才继续。随后只在当前可见 DOM 中匹配文本精确为“押后”的启用真实控件：原生 `button` 或类名含 `defer-button` 的 `div`；等待唯一、可见且标题精确为“押后原因”的弹层，在其唯一 textarea 写入 `1` 并派发输入事件，再只点击同一弹层按钮组的“确定”。每次自动点击前必须等页面全部 fetch/XHR 结算，并在最后一次网络活动后持续静默 1 秒；面板“等待网络结算”会显示未结算数量，20 秒内未满足即停止。跨世界活动消息只包含计数和序号，不含 URL、参数、响应或凭据。确认后仅以 Receive ItemID 已改变为进入下一题的依据；非可押后状态、元素缺失/歧义、写入失败或下一题未验证都会立即停止，绝不重试、跳过、点击“提交”、领取、保存或调用 AIDP 接口。下一题初始化后没有可用“押后”控件时以“已无可押后数据”正常结束；用户停止会在确认前点击同一弹层内的“取消”，确认已发送后不再动作。
- 台州详情页不显示“识别完成后自动填入”；保存的非空自定义 Prompt 不迁移、不覆盖，并原样作为完整 systemPrompt，完全决定模型语义和输出格式。后端只附带片段与标注上下文，不追加转换、听写或输出格式规则；清空后回退默认 Prompt；旧自动填入 storage 值不读取、不迁移。
- 其他 AIDP 脚本的设置不受影响。

- 自动流程进入下一题后，会先按新的 Receive ItemID 等待同题 Search Item 完整快照。`waiting` 与 `stale` 仅在 20 秒内进行只读等待，不触发导入请求；快照就绪后才导入并刷新，其他上下文异常仍立即停止。

## 检查包只读识别

- 精确支持路由 `scan-v3/14`；`mark-v3` 继续保持既有可写标注行为。
- 检查包从 `GetWorkItem` 的最小快照读取当前媒体与 `regions`，用表格行键关联 `region.id`，不依赖动态 textarea ID。
- 行内识别和批量识别只显示 `listenText`、用量/人民币估算与复制操作；批量范围固定为当前题当前可见分段，支持停止。
- 检查包不显示写入型分段操作，也不会修改 textarea、调用 `SubmitTempItemAnswer`、暂存、提交、领取、切题或启动录音导入流程。

## 本地验证

1. 在扩展管理页加载 `extension/`。
2. 刷新 AIDP 标注详情页。
3. 单段识别后，对比 textarea 与接口响应的 `listenText` 是否逐字符一致。
4. 批量只选择部分段，确认仅这些段的 `regions[*].txt` 暂存更新，且不提交、不切题。
5. 使用脱敏测试任务编号，分别选择 Search Item 响应中的第一条和非第一条数据，确认都只在 Receive ItemID 精确匹配时进入就绪；确认被动匹配状态只影响“添加数据”按钮及悬停说明，顶部保持公共文案或最近操作结果。清除本地映射后，服务器已有映射的题目应在手动刷新时只调用一次恢复接口并显示真实结果；服务器也无映射时保持空状态且不创建。首次添加产生一次创建和一次自动结果查询；再次添加由服务器核验并返回原条目。让页面重绘辅助区并等待多个同步周期，确认不会自动调用恢复接口，有效录音状态、同一个音频播放器及播放进度不变；完成文本和音频不得出现在 AIDP 输入框或暂存请求中。
6. 仅使用指定的脱敏测试任务，点击“全自动导入并押后”，先完成一轮后点击“停止”复核：确认只出现当前录音条目的导入/刷新、原生“押后”弹层填写 `1`、弹层内“确定”及 Receive ItemID 切换；每次自动点击前先显示页面 fetch/XHR 已结算后的 1 秒静默等待，未结算数量持续显示且 20 秒后停止；`AVAILABLE` 与 `SUBMITTED` 均可继续，其他状态、缺失/多重弹层、20 秒未进入下一题与手动停止均会停止且不重复确认；不得出现“提交”、领取、保存或 AIDP 接口写请求。
