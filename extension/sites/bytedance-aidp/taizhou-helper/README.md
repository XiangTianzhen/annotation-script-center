# 台州话 AIDP 运行时

## 定位

台州话脚本用于诊断百炼模型与标注平台模型的差异：每段音频只请求一次 Qwen Omni，后端再将字符串原始输出逐字符映射为 `listenText` 供平台文本框使用。

## 原始听音直填契约

- 后端成功结果的唯一业务文本字段是 `listenText`；它是扩展/API 兼容字段，不是模型要求返回的 JSON 字段。
- `listenText` 按原样传递；不做 trim、空白折叠、普通话转换、数字改写、标点规整或重复压缩。
- 后端只在原始模型输出为字符串时逐字符映射 `listenText`；空字符串或非字符串不写入 textarea 或暂存数据。所有非空字符串均会原样写入，包括模型意外输出的 JSON、Markdown 或解释文字。
- 单段与行内识别通过真实 textarea 的输入事件直接写入 `listenText`。
- 批量只处理当前题当前页选中的段，收集非空 `listenText` 后一次通过 `SubmitTempItemAnswer` 写入 `regions[*].txt`。
- 批量停止后不再发新请求；已在途结果不会产生二次写回操作。
- 全程不触发保存、提交或切题，且不修改 `regions[*].ms`。

## 界面与设置

- 行内按钮始终为“识别音频”；不保留待填入、强制填入或风险提示状态。
- AI 信息区显示“原始听音”、调用消耗以及 `raw/debug`。
- Options“基础设置”的“录音平台任务编号”默认空且保存时去除首尾空白；空值不显示导入按钮，也不查询结果。
- 配置任务编号后，详情页顶部只在 Search Item 与当前 Receive ItemID 一致、快照有效且至少包含一种参考内容时启用“添加数据”，按钮固定在“清空画段”左侧。单次 Search Item 响应包含多条数据时，会先提取全部条目的最小安全字段，再按当前 Receive ItemID 精确选择，不固定取第一条，也不按页面位置猜测。等待、过期、错题或空内容时按钮保持禁用，并通过按钮悬停说明具体原因；这些被动状态不覆盖顶部公共状态或导入、刷新、识别等主动操作结果。切换题目时顶部恢复“台州话脚本已就绪，可使用当前页面中的辅助功能。”。导入固定使用当前完整题目，不按画段拆分；点击前和创建流程内部都会检查当前任务编号与 ItemID 的本地同步映射，已存在时只弹窗显示录音条目，不发创建或结果请求，也不重绘已有结果。
- Search Item 的公网 HTTPS 音视频地址不由扩展下载；“添加数据”只把参考文字和原始 URL 发送到脚本中心创建端点，浏览器不会产生媒体 GET 或参考媒体上传请求，也不会发送 AIDP Cookie、Authorization 或 Session。
- “当前媒体信息”默认折叠，从当前 Receive 条目展示音频和视频地址，不展示模板；存在对应地址时可复制保留完整查询参数的 URL，缺少视频时只显示“无视频”。录音任务导入仍使用 Search Item 一致性校验，并由脚本中心语法校验后直接转发 URL。
- 辅助面板“当前录音平台结果”默认折叠；界面不显示内部关联用的 sourceItemId，始终显示“录音条目”，未导入时显示“还未导入该条目”，导入后显示 itemCode、友好状态、完成文本和音频。首次创建立即采用创建响应中的真实 itemCode 与 status；服务端幂等重放会重建丢失的本地映射并提示条目已存在。状态映射覆盖待领取、待录音、待审核领取、审核中、待返修、已完成和已废弃，未来未知状态直接显示原始状态码。任何映射读取前先登记题目与进入代次，每次进入匹配题目只读取映射并自动查询、渲染一次；同题目的周期性 DOM 同步直接跳过，不再读取映射、查询缓存、渲染结果或重建音频播放器，只有用户点击“刷新录音结果”才进行后续查询和更新。未导入时手动刷新只显示正常空状态，不发结果请求。A→B→A 再次进入 A 时创建新代次并重新查询，旧题的慢映射、结果和错误不渲染。AIDP 重建辅助面板时直接从 UI 内存恢复最近结果，不调用服务器。结果音频只接受脚本中心预期相对 API 路径及双段 base64url token，不展示结果视频、不写回 AIDP。
- 人工导入固定使用启动时的任务编号与 sourceItemId；导入中切题仍只保存原题映射，不把原题成功或失败状态渲染到新题。
- 台州详情页不显示“识别完成后自动填入”；保存的非空自定义 Prompt 不迁移、不覆盖，并原样作为完整 systemPrompt，完全决定模型语义和输出格式。后端只附带片段与标注上下文，不追加转换、听写或输出格式规则；清空后回退默认 Prompt；旧自动填入 storage 值不读取、不迁移。
- 其他 AIDP 脚本的设置不受影响。

## 本地验证

1. 在扩展管理页加载 `extension/`。
2. 刷新 AIDP 标注详情页。
3. 单段识别后，对比 textarea 与接口响应的 `listenText` 是否逐字符一致。
4. 批量只选择部分段，确认仅这些段的 `regions[*].txt` 暂存更新，且不提交、不切题。
5. 使用脱敏测试任务编号，分别选择 Search Item 响应中的第一条和非第一条数据，确认都只在 Receive ItemID 精确匹配时进入就绪；确认被动匹配状态只影响“添加数据”按钮及悬停说明，顶部保持公共文案或最近操作结果。未导入时点击刷新应保持空状态且无请求；首次添加只创建一次并显示响应状态；已导入条目再次点击只弹窗，不改变结果卡或音频播放。让页面重绘辅助区并等待多个同步周期，确认有效录音状态、同一个音频播放器及播放进度不变，只有有映射时手动刷新才产生第二次结果查询；完成文本和音频不得出现在 AIDP 输入框或暂存请求中。
