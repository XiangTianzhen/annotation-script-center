# 数加加泸州话识别运行时

该目录是 `shujiajiaLuzhouHelper` 的浏览器运行时，默认关闭，只在数加加分段标注页启用。

## 文件职责

- `page-world/network-observer.js`：从 execute 请求查询参数读取 `taskId`，从响应 `data.detail` 读取 `dataId` 与音频来源；脚本启用前只在 MAIN world 内存保留最近一次最小快照，启用后立即获取音频，并兼容被动捕获音频响应。XHR 只包装 `open` 记录私有元数据并监听生命周期，保持平台原生 `send` 不变，无关请求不进入业务处理。
- `whole-segment-controller.js`：切题后 AI 结果区重挂与 Peaks.js 波形的就绪等待、零段落守卫、段落读取、可信 `Shift + 拖拽`、单段与两像素边界验证。
- `data-api.js`：严格定位单个可编辑段落或唯一选中行，派发原生转写输入事件，并唯一匹配 `Category1（多选）` 的 OVERLAP 原生符号控件。
- `ai-recommendation.js`：只发送 `aiStages.listen`，调用单阶段 Omni 泸州方言识别接口并附带 AI 使用人。
- `ui-panel.js`：控制区优先追加到 `.tabs-container`，结果区优先追加到 `.transfer`；零段状态缺少这些节点时使用扩展专属回退挂载点，平台节点生成后自动迁回，并维护只增不减的结果框挂载代次。
- `shortcuts.js`：整音频划一段、识别整段、填入识别结果和两个 OVERLAP 原生操作共五项空默认快捷键；转写输入框内仅放行 OVERLAP 动作。
- `content.js`：按 `taskId + dataId` 跨 frame 对题，编排音频、切题自动划段、画段后自动识别、待暂存版本和幂等挂载。

## 当前边界

- 已有任意段落时不画段，不删除、不合并、不覆盖。
- “进入新条目后自动划整段”和“助手画段成功后自动识别”默认关闭；首次加载当前条目只建立基线，后续切题才触发自动划段，每个条目在当前页面会话内最多尝试一次。
- 切题自动划段以扩展结果框 `[data-asc-shujiajia-luzhou-drawer]` 的重新挂载为第一道就绪标记：首次条目记录挂载代次，后续条目只接受代次增加且唯一、已连接、未隐藏、可见、尺寸有效的结果框，再等待音频时长与波形宽度就绪。重复 `ensureMounted()` 不增加代次；观察仅使用 `MutationObserver`，不读取 Resource Timing，也不主动请求字体、WASM 或 favicon。10 秒内未确认结果框重挂则本题取消且不降级；手动画段不受该 DOM 门禁影响。自动识别只接受同题音频，音频未就绪时等待，切题、音频失败、关闭对应开关或禁用脚本时取消。
- 整段绘制由 iframe 请求顶层换算坐标，再由后台在精确数加加标注路由内发送受限可信输入；不直接修改 annotation JSON。
- Peaks.js 段落通过表格行数和当前“区域”文字验证；兼容 `【开始 结束】` 与带逗号格式，首尾容差不超过两个波形像素。超出容差时保留段落并提示人工检查，不自动触发 Delete。
- 识别不依赖段落数量，只要求当前条目身份与同题音频有效；零段、单段和多段均可直接识别。
- 识别成功后，默认仅在恰好一个可见、可编辑转写框时自动填入并标记待暂存；零段或多段保留结果并提示“当前段数不是 1，未自动填入”。
- 人工“填入转写”只写入唯一 `.el-table__row.current-row` 内的唯一可编辑 `.transfer-input`；没有唯一选中行时关闭失败，不回退到第一段。
- OVERLAP 快捷键只点击 `Category1（多选）` 分组内唯一可见、可用的 `[OVERLAP/]` 或 `[/OVERLAP]` 原生项；歧义、隐藏、禁用或缺失均拒绝。成功后只标记待暂存，不直接拼接文本。
- 同一条目已有识别请求运行时，按钮、快捷键和自动流程的重复触发会被拒绝；自动填入前再次读取开关，关闭后不会发生晚到写入。
- 有效性、播放、保存和提交使用平台原生控件或平台快捷键；扩展不拦截平台原生按钮，也不自动暂存或提交。
- 暂存成功必须同时匹配当前条目、最近一次待暂存版本和业务成功响应；切题会清空旧音频与旧识别结果。
- 脚本或 AI 识别在 Options 中关闭后，后续快捷键动作会即时拒绝，页面观察器停止采集。
- 结果区始终显示；未识别时显示占位状态，识别后显示“泸州方言文本”及单阶段 Token、耗时和人民币估算，不提供展开或关闭动作，只保留人工“填入转写”。Qwen 请求失败时追加“AI 错误诊断”，展示醒目的中文“错误说明”、百炼状态/错误码、标注为“上游原文”的摘要、requestId 和可复制的脱敏原始响应；失败不覆盖已有识别文本，下一次成功或切题会清除旧诊断。
- execute 若早于脚本设置加载完成，观察器只暂存最近一次的请求 `taskId` 与响应 `dataId + fileFolder` 最小快照；确认启用后立即消费，禁用或切题时清除，不主动重放 execute 请求。
- 只接受 execute 响应中 `https://storage.shujiajia.com/` 的完整 HTTPS 音频地址；页面世界请求不附带数加加 Cookie，原始地址只存在于 MAIN world 临时内存，不跨世界、不持久化、不记录；签名参数、Token、`audioDataUrl` 和真实任务数据同样不进入日志或资料。
- AI 错误原始响应由后端先解析并再次脱敏，最多保留 `20000` 字符；前端不接收或展示 API Key、Authorization、Cookie、Prompt、音频 Base64、请求头或完整 URL。
- 音频失败只跨世界发送 `contextId` 与安全错误码，区分条目身份缺失、来源不合法、下载失败、格式不支持和超过 10MB，不包含文件名、查询参数或底层异常文本。

页面与请求依据见[数加加平台资料](../../../../platform-resources/shujiajia/README.md)。
